# Say What Actually Broke

This entry provides a standalone Node 22 program that writes a single line of error copy to entry.txt in a fully deterministic manner, requiring no network calls or external dependencies. Stripping away corporate euphemisms and technical noise to reveal the raw truth of failure is what makes a single sincere sentence the entire game.

## How to Run

Execute the main script directly using Node.js:

```bash
node main.ts
```

To output the file to a custom directory, set the `MAKEFUN_OUTPUT_DIR` environment variable:

```bash
MAKEFUN_OUTPUT_DIR=./custom_dir node main.ts
```
